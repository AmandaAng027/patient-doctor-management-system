#### **# Minimum System Specifications**





###### **-- Hardware Requirements**



Operating System: 64-bit Windows 10 or Windows 11 (recommended).



Processor (CPU): 1.4GHz dual-core processor (Intel Core i3 / 

AMD Ryzen 3 or equivalent)



Memory (RAM): 4 GB RAM minimum. 8 GB recommended.



Storage: 1 GB free disk space for application files.



Display: 1280 x 720 resolution minimum. 





###### \-- **Software Environment \& Dependencies**



Python: Version 3.13.x (the application was explicitly developed and tested on Python 3.13.5)



Database Engine: Microsoft SQL Server 2022 (RTM) - 16.0.1000.6 (X64) 



Database Management Tool: SQL Server Management Studio 20.2.30.0



Driver: ODBC Driver 17 for SQL Server
